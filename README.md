# mulberrysamos.com — deployed build

Static build of the Mulberry Residences website (four stays in Kokkari, Samos), served via GitHub Pages.

- **Source of truth:** the private `philpottm/mulberry` repository, `website-prototype/` (source.html + style.css + app.js + reference.js + content drafts; build.py assembles index.html). This repo holds the built output only — edit there, rebuild, then copy `index.html`, `robots.txt`, `CNAME` and `assets/` here.
- **Photographs** show the apartments **before the renovation**; a banner on every page says so. Property pages carry a before/after pair: pre-renovation photo sheet vs an AI impression of the planned renovation (Olive Grove / Vineyard Retreat theme from the design playbook). AI renders are impressions, not photographs of finished rooms.
- **Enquiry form** posts via formsubmit.co to `hello@mulberrysamos.com` (Migadu). FormSubmit requires a one-time activation click in the confirmation email sent to that address after the first submission.
- Booking/date form is a preview only: no availability, prices or reservations are connected yet.
